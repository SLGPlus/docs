SLGPlus est le portail d'informations du collège Saint-Louis de Gonzague. Il rassemble les actualités de l'établissement, la gestion des objets perdus, la boîte à idées des élèves, les informations de cantine, les disponibilités du CDI et un forum de discussion. Le projet est développé par une équipe d'élèves et utilise une stack technique moderne alliant Python, Go, JavaScript et PHP. Ci dessous la documentation complète à des fins techniques et de Présentation.

<Danger>
  AVERTISSEMENT: Les documents présents sur ce site ainsi que le code source de SLGPlus est destiné à être consulté par les techniciens & devs SLGPlus UNIQUEMENT.
</Danger>

## Stack technique

Le projet repose sur plusieurs langages et technologies :

<Tabs>
  <Tab title="Backend">
    - **Python 3.10** avec Flask et Flask-RESTful pour l'API principale
    - **Go** pour le microservice de connexion ÉcoleDirecte
    - **Waitress** comme serveur WSGI (32 threads)
    - **MariaDB** pour la base de données
  </Tab>
  <Tab title="Frontend">
    - **HTML, CSS et JavaScript** vanilla, sans framework
    - **Bootstrap 5.3.8** et Bootstrap Icons
    - **WebAssembly** pour l'exécution de Doom dans le navigateur (easter egg)
  </Tab>
  <Tab title="Forum">
    - **PHP** avec Flarum 1.8
    - **Composer** pour la gestion des extensions
  </Tab>
</Tabs>

La procédure de démarrage rapide se trouve ici [Quickstart](/quickstart).
