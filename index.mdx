SLGPlus est le portail d'informations du collège Saint-Louis de Gonzague. Il rassemble les actualités de l'établissement, la gestion des objets perdus, la boîte à idées des élèves, les informations de cantine, les disponibilités du CDI et un forum de discussion. Le projet est développé par une équipe d'élèves et utilise une stack technique moderne alliant Python, Go, JavaScript et PHP.

## Stack technique

Le projet repose sur plusieurs langages et technologies complémentaires :

<Tabs>
  <Tab title="Backend">
    - **Python 3.10+** avec Flask et Flask-RESTful pour l'API principale
    - **Go** pour le microservice de connexion ÉcoleDirecte
    - **Waitress** comme serveur WSGI (32 threads)
    - **MariaDB** pour le stockage relationnel
  </Tab>
  <Tab title="Frontend">
    - **HTML, CSS et JavaScript** vanilla, sans framework
    - **Bootstrap 5.3.8** et Bootstrap Icons
    - **WebAssembly** pour l'exécution de Doom dans le navigateur
  </Tab>
  <Tab title="Forum">
    - **PHP** avec Flarum 1.8
    - **Composer** pour la gestion des extensions
  </Tab>
</Tabs>

## Démarrage rapide

<Steps>
  <Step title="Cloner les dépôts">
    Récupérez le backend et le frontend depuis l'organisation GitHub SLGPlus.
  </Step>
  <Step title="Installer les dépendances">
    Installez Python 3.10, MariaDB, Go et PHP, puis les packages Python requis.
  </Step>
  <Step title="Configurer l'API">
    Copiez `api_config/config_template.yml` vers `api_source/config.yml` et renseignez vos valeurs.
  </Step>
  <Step title="Lancer les services">
    Démarrez l'API Flask avec `python app.py`, le microservice Go avec `go run edlogin.go`, et le serveur web pour le frontend.
  </Step>
</Steps>

Pour une procédure détaillée, consultez la page [Quickstart](/quickstart).
