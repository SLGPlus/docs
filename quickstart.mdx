Ce guide explique comment faire tourner le backend SLGPlus sur votre machine en quelques minutes. Vous installerez les dépendances, configurerez la base de données et effectuerez vos premières requêtes sur l'API locale.

<Info>
  L'API Flask écoute par défaut sur le port 5000. Le microservice ÉcoleDirecte en Go écoute sur le port 8080.
</Info>

## Prérequis

Avant de commencer, assurez-vous d'avoir installé :

- Python 3.10 ou supérieur (le code utilise `match`)
- MariaDB
- Go 1.22+
- PHP et Composer (pour le forum Flarum)

## Installation

<Steps>
  <Step title="Cloner le dépôt backend">
    ```bash
    git clone https://github.com/SLGPlus/SLGPlus-Backend.git
    cd SLGPlus-Backend
    ```
  </Step>
  <Step title="Installer les dépendances Python">
    ```bash
    pip install flask flask-restful flask-cors mariadb pyyaml requests openpyxl pytz werkzeug waitress
    ```
  </Step>
  <Step title="Configurer la base de données">
    Créez une base de données MariaDB nommée `slgplus` et assurez-vous que les tables requises existent (voir [Base de données](/reference/base-de-donnees)).
  </Step>
  <Step title="Copier le fichier de configuration">
    ```bash
    cp api_config/config_template.yml api_source/config.yml
    ```

    Renseignez ensuite les champs suivants dans `api_source/config.yml` :

    ```yaml
    database:
      host: "localhost"
      port: 3306
      user: "slgplus"
      password: "<motdepasse>"
      database: "slgplus"
      pool_size: 64
    
    apikeys:
      flarum_master: "VOTRE_CLE_FLARUM"
      gemini_keys:
        - "VOTRE_CLE_GEMINI"
    ```

    <Warning>
      Le dépôt contient des secrets codés en dur dans l'historique Git. Remplacez-les par des valeurs propres et placez `config.yml` dans votre `.gitignore`. Le modèle de configuration est incomplet : les clés `security.crontoken` et `forum.limits` sont lues par l'application mais absentes du template.
    </Warning>
  </Step>
  <Step title="Lancer l'API principale">
    ```bash
    cd api_source
    python app.py
    ```

    L'API démarre avec Waitress sur `0.0.0.0:5000`.
  </Step>
  <Step title="Lancer le microservice ÉcoleDirecte">
    Dans un autre terminal :

    ```bash
    cd api_source
    go run edlogin.go
    ```

    Le service écoute sur `localhost:8080`.
  </Step>
</Steps>

## Vérifier l'installation

### Premier appel : ping de l'API

<CodeGroup>

```bash cURL
  curl http://localhost:5000/
```

```python Python
import requests
response = requests.get("http://localhost:5000/")
print(response.json())
```

```javascript JavaScript
fetch("http://localhost:5000/")
  .then(r => r.json())
  .then(console.log);
```

</CodeGroup>

Réponse attendue :

```json
{
  "message": "pong",
  "version": "v2.0.2-SQL",
  "status": {
    "maintenance": false
  }
}
```

### Tester la connexion élèves

Avec un PIN valide enregistré dans la base :

<CodeGroup>

```bash cURL
curl -X POST http://localhost:5000/checkeleves \
  -H "Content-Type: application/json" \
  -d '{"pin": "1234", "IP": "127.0.0.1"}'
```

```python Python
import requests
response = requests.post(
    "http://localhost:5000/checkeleves",
    json={"pin": "1234", "IP": "127.0.0.1"}
)
print(response.json())
```

```javascript JavaScript
fetch("http://localhost:5000/checkeleves", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ pin: "1234", IP: "127.0.0.1" })
})
.then(r => r.json())
.then(console.log);
```

</CodeGroup>

Réponse en cas de succès :

```json
{
  "message": "success",
  "token": "a1b2c3d4e5f6..."
}
```
