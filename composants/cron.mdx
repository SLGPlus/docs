Le fichier `api_source/cron.py` est un script Python simple qui appelle la route de remise à zéro des compteurs du forum. Il doit être exécuté une fois par jour.

## Fonctionnement

Le script effectue une requête `POST` vers `http://localhost:5000/cron/cleancounter` avec un jeton d'authentification :

```python title="cron.py"
import requests

print("SLGPlus Tâches du jour")
print("Nettoyage des compteurs quotidiens...")

url = 'http://localhost:5000/cron/cleancounter'
payload = {'token': '<crontoken>'}

response = requests.post(url, json=payload)
print(response.text)
print(response.status_code)
print("Tâches exécutées avec succès !")
```

<Warning>
  Le jeton est codé en dur dans le fichier `cron.py`. Cette valeur doit être déplacée dans une variable d'environnement ou le fichier `config.yml`, puis renouvelée régulièrement.
</Warning>

Il est exécuté tout les minuits via le planificateur de tâches, côté serveur.

## Ce que fait la route côté API

La classe `CleanCounters` dans `app.py` effectue les opérations suivantes :

<Steps>
  <Step title="Vérification du jeton">
    Le jeton fourni est comparé à `CONFIG["security"]["crontoken"]`
  </Step>
  <Step title="Nettoyage des groupes">
    Pour chaque utilisateur dans `forum_limit_posts` ou `forum_limit_discussions`, le groupe 9 est retiré
  </Step>
  <Step title="Vidage des tables">
    `TRUNCATE TABLE forum_limit_discussions` et `TRUNCATE TABLE forum_limit_posts`
  </Step>
</Steps>

```python title="CleanCounters"
class CleanCounters(Resource):
    def post(self):
        args = request.json
        if args["token"] != CONFIG["security"]["crontoken"]:
            return {"message": "Not authorized"}, 401

        conn = db()
        cur = conn.cursor(dictionary=True)
        cur.execute("""
            SELECT userid FROM forum_limit_discussions
            UNION
            SELECT userid FROM forum_limit_posts
        """)
        rows = cur.fetchall()
        for row in rows:
            userid = row["userid"]
            _remove_flarum_groups(userid, 9)

        cur.execute("TRUNCATE TABLE forum_limit_discussions")
        cur.execute("TRUNCATE TABLE forum_limit_posts")
        conn.commit()
        conn.close()
        return {"message": "success"}, 200
```
